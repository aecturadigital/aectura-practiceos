# Master Specification Reference

Refer to the primary project specification located at [docs/master-specification.md](../../../../docs/master-specification.md).

Key Highlights:
- Modular Multi-Tenant Architecture (Next.js App Router, TypeScript)
- PostgreSQL + Drizzle ORM (PgBouncer connection pooling)
- Cloudflare R2 (Pre-signed URLs for medical and intake files)
- n8n Event-driven Webhooks for asynchronous communications
- Guardrailed AI Receptionist bounded by clinical safety rules
